# 2026_09_08_gdp_post_it_to_learn_with_graph_node

> Use Godot's `GraphNode` as Post-It notes to learn, organize, and track skills.   

I am paying for [Miro](https://miro.com/index/) mainly to structure my workshops and manage my tasks.   

But when I think about it, all I really need are virtual Post-It notes.   

Then I discovered Godot's `GraphNode` and realized that it already provides almost everything I need to build a virtual Post-It board, with a few extra steps.    

This Godot package lets you create boards made of Post-It-style notes that can be saved to and loaded from text files.    

The goal is to use these boards not only for workshop planning and task management, but also as a simple way to organize knowledge, track what I am learning, and keep a visual record of skills and topics I want to check.
